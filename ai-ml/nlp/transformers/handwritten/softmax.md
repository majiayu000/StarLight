# Softmax的数学定义
```
softmax(x_i) = e^(x_i) / Σ(e^(x_j))
```

# 具体例子
输入一个向量：
```
scores = [2.0, 1.0, 0.1]
```

计算步骤：
```
# 步骤1：计算每个元素的指数
e^2.0 = 7.39
e^1.0 = 2.72  
e^0.1 = 1.11

# 步骤2：计算所有指数的和
sum = 7.39 + 2.72 + 1.11 = 11.22

# 步骤3：每个指数除以总和
softmax_result = [
    7.39/11.22 = 0.66,
    2.72/11.22 = 0.24,
    1.11/11.22 = 0.10
]
```


# Softmax的特点

1. 输出是概率分布
```
# 所有输出值：
# - 都在0到1之间
# - 加起来等于1
0.66 + 0.24 + 0.10 = 1.0 ✓
```

2. 突出最大值
```
# 输入: [2.0, 1.0, 0.1]
# 输出: [0.66, 0.24, 0.10]
# 最大的2.0变成了0.66（66%的权重）
```


## 在注意力机制中的作用
### 注意力分数 → 注意力权重
```
# 假设"爱"这个词对其他词的注意力分数：
scores = [
    0.8,  # 对"我"的分数
    0.3,  # 对"爱"自己的分数  
    0.9,  # 对"你"的分数
    0.1   # 对"<PAD>"的分数
]

# 应用softmax后变成权重：
attention_weights = [
    0.35,  # 35%注意力给"我"
    0.21,  # 21%注意力给"爱"
    0.39,  # 39%注意力给"你"  
    0.05   # 5%注意力给"<PAD>"
]
# 总和 = 1.0

```

## 为什么用softmax？
为什么用softmax？
1. 归一化：确保所有权重加起来等于1
2. 概率解释：可以理解为"注意力分配的概率"
3. 可微分：可以用于反向传播训练
